## Por qué, cómo y para qué

Llevaba tiempo con ganas de tener un sitio donde frikear con tecnología sin miedo a romper nada. Probar cosas, desplegar servicios, montar una nube privada, un servidor web... todas esas cosas que se te pasan por la cabeza.

El problema era el de siempre, no quería levantarlos en mi pc y necesitaba una máquina dedicada para esto. Asi que Empecé mirando opciones y me decanté por un mini PC Soyo con Intel N150 y 16GB de RAM DDR4. No es una bestia, pero para lo que quiero hacer es más que suficiente. Bajo consumo, silencioso y cabe en cualquier sitio.

La pregunta era qué sistema operativo instalarle.


## Proxmox: qué es y por qué hay tres productos

Antes de nada, aclarar algo que puede liar al principio: [Proxmox](https://www.proxmox.com) tiene tres productos distintos:

- **[Proxmox VE](https://www.proxmox.com/en/proxmox-virtual-environment/overview)** (Virtual Environment): hipervisor para gestionar VMs y contenedores. <------- Es el que nos interesa.
- **[Proxmox Backup Server](https://www.proxmox.com/en/proxmox-backup-server/overview)**: solución dedicada para backups.
- **[Proxmox Mail Gateway](https://www.proxmox.com/en/proxmox-mail-gateway/overview)**: proxy para correo electrónico.

Yo instalé **Proxmox VE**.

La opción más sencilla hubiera sido instalar Ubuntu y tirar. Pero me decanté por Proxmox VE por varias razones:

- Es ligero. No consume recursos innecesarios, el hipervisor hace su trabajo y punto.
- Puedes desplegar tanto máquinas virtuales (KVM) como contenedores (LXC) desde el mismo panel web.
- Tiene una comunidad enorme detrás. Scripts, documentación, soluciones a problemas... hay de todo.
- El aislamiento entre servicios es real. Si la lío en una VM no afecta a las demás.
- Si mañana el mini pc se queda corto puedo hacer un cluster y problema resuelto

  La verdad que me pareció de lejos la mejor opción


## Instalación

La instalación es bastante directa. Descargas la [ISO de Proxmox VE](https://www.proxmox.com/en/downloads/proxmox-virtual-environment/iso) desde la web oficial, la grabas en un USB (yo use rufus). En unos minutos tienes el panel accesible desde el navegador en `https://IP:8006`.

La documentación oficial está en [pve.proxmox.com/wiki](https://pve.proxmox.com/wiki/Main_Page) y es bastante completa por si quieres echar un ojo.

## Post-instalación con community-scripts

Tras instalar, lo primero que hice fue pasarle algunos scripts de la comunidad entre ellos el de post-instalación de [community-scripts.org](https://community-scripts.org/scripts/post-pve-install).

El script de post-instalación concretamente hace varias cosas útiles:

- Configura los repositorios gratuitos (Proxmox tiene suscripción de pago, pero los repositorios community son perfectamente válidos para un homelab).
- Elimina el aviso de suscripción que aparece cada vez que entras al panel.
- Desactiva servicios de HA que en un nodo único no sirven para nada y consumen RAM.
- Ofrece actualizar el sistema al final.

Para ejecutarlo, desde la shell de Proxmox:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/community-scripts/ProxmoxVE/main/tools/pve/post-pve-install.sh)"
```

Puedes ver todos los scripts disponibles en [community-scripts.org](https://community-scripts.org).

## Optimización de consumo

Como el mini PC va a estar encendido varias horas al día, quise reducir el consumo al mínimo. Dos cosas:

**CPU governor en modo powersave:**
```bash
apt install cpufrequtils -y
echo 'GOVERNOR="powersave"' > /etc/default/cpufrequtils
systemctl restart cpufrequtils
```

**PowerTop para optimización automática:**
```bash
apt install powertop -y
powertop --auto-tune
```

Y para que se aplique en cada arranque, un servicio systemd:

```bash
cat > /etc/systemd/system/powertop.service << EOF
[Unit]
Description=PowerTop auto tune

[Service]
Type=oneshot
ExecStart=/usr/sbin/powertop --auto-tune

[Install]
WantedBy=multi-user.target
EOF

systemctl enable powertop
```
